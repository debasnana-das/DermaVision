# ACNE04 demonstration samples

This folder contains four unmodified sample photographs from the ACNE04 dataset, selected from the canonical fold-0 held-out test partition (the source repository's NNEW_test_0.txt).

| File | Dataset severity grade | Original filename |
|---|---|---|
| acne04_mild_levle0_103.jpg | Mild (level 0) | levle0_103.jpg |
| acne04_moderate_levle1_503.jpg | Moderate (level 1) | levle1_503.jpg |
| acne04_severe_levle2_19.jpg | Severe (level 2) | levle2_19.jpg |
| acne04_very_severe_levle3_33.jpg | Very severe (level 3) | levle3_33.jpg |

## Source and citation

- Dataset: [Layered-Labs/ACNE04 on Hugging Face](https://huggingface.co/datasets/Layered-Labs/ACNE04)
- Original project: [xpwu95/LDL](https://github.com/xpwu95/LDL)
- Image files were retrieved from the public mirror [anaynasingh/acne04-dataset](https://github.com/anaynasingh/acne04-dataset), which reproduces the original ACNE04 classification image filenames.
- Paper: X. Wu et al., "Joint Acne Image Grading and Counting via Label Distribution Learning", ICCV 2019.
